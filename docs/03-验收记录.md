## 已验证

- Next.js 16.3.5 / React 19.3.0 / Node 24.19.0 的生产 build 和 standalone start 通过。
- 所有公共业务页面为请求时 SSR；关闭 JavaScript 仍能看到公共内容。
- TypeScript strict 与 ESLint 通过。
- 33 个单元测试通过：17 个费用/规则用例，16 个分词金样本用例。

5. **公网性能、证书续期与回滚演练**：需真实部署环境；没有提前打勾。
