## 视频收录来源

仅提供编辑导读与原站入口，不搬运原视频，不虚构观看量、评分或时长。主要选择理由是官方教学背景、可跟做任务与创作者场景相关；并非声称完整观看和评审每门课程。

- Blender Studio：[Blender 2.8 Fundamentals](https://studio.blender.org/training/blender-2-8-fundamentals/)。明确标明旧版本，操作对照当前界面。
- Unity Learn：[Unity Essentials](https://learn.unity.com/pathway/unity-essentials)。系统学习引擎与交互。
- Epic Games：[Your First Hour in Unreal Engine](https://dev.epicgames.com/documentation/unreal-engine/first-hour-in-unreal-engine)。官方视频系列及工程文件。
- Runway Academy：[Creating with Chat Mode](https://academy.runwayml.com/tutorial/creating-with-chat-mode) 与[课程目录](https://academy.runwayml.com/)。AI 视频制作。
- Blackmagic Design：[DaVinci Resolve 官方培训](https://www.blackmagicdesign.com/cn/products/davinciresolve/training)。剪辑、调色与音频；中文页面，视频语言以原站为准。

平台条目包含官方链接、能力、限制、输入输出及核验日期。覆盖 Claude、DeepSeek、Gemini、Kimi、Mistral、Qwen、豆包、GLM、Midjourney、Recraft、Ideogram、FLUX、Firefly、Suno、Dify、Hugging Face、Ollama、LM Studio、Unreal、Unity、DaVinci，以及原有 11 项工具。

## 数据库与接口

沿用 documents 表，不增加新数据库服务。knowledge 可选 video 对象，由 shared/cms.ts 验证，链接只允许现有安全 URL 规则。列表返回摘要和视频元信息，详情提供正文；视频不自动加载外站播放器。

`GET /api/v1/library/learn?format=article|practice|video&category=...&q=...&page=...`，默认 18 条。应用场景由 bootstrap 的 scenarios 提供。

`GET /api/admin/community/users?page=...&q=...&type=registered|preset&state=active|disabled`，每页 20 条，后台身份验证沿用既有中间件。参数经 Zod 验证，查询使用参数绑定，搜索 `%` 按普通文本处理。不返回密码、哈希或会话令牌。状态修改继续写入 history；服务端拒绝恢复预置账号的登录。

## 内容发布与回滚

`backend/src/content/expansion.json` 是版本化编辑内容包；`content-expansion.ts` 在启动时执行一次事务导入，以 meta.learningExpansion20260917 记录完成状态。只插入缺失 ID，不覆盖已有文档，不因重启恢复已撤下或删除的内容。原始场景只有 revision=1 且草稿与发布版一致时才追加关联，修改记录写 history。

论坛展示迁移以 meta.starterPresentation20260917 记录；只对 demo=1 行移除已知重复前缀，不改账号、发布时间、审核状态、密码及真实用户内容。欢迎帖与社区规则保留来源说明。

部署沿用 GitHub CI → 测试环境 → 指定 SHA 晋升生产。上线前备份由现有 deploy.sh 完成。回退镜像不会自动回退数据库，新增内容会保留；需要恢复数据时使用上线前数据库备份，先评估上线后的用户写入。不要删除迁移标记来尝试回滚。
