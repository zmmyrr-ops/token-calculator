# AI眼里的你：手机通用版

支持豆包、DeepSeek及其他可以处理长文本指令的聊天应用。不依赖应用接口、自动跳转或读取全账号历史。

## 用户教程
1. 打开 `/ai-eyes`，在手机入口选择平台。
2. 选择已有对话判断或简短问答。复制完整指令发给AI；已有对话不足时也会追问。
3. 等待AI给出结果码，复制完整JSON代码块，回本站粘贴。
4. 确认不含个人敏感信息，生成自己的结果，可修改昵称、生成封面并保存。
5. 分享必须在结果页预览并确认；导入结果会标明用户导入，不作为平台认证。

## 实现
- `shared/ai-eyes-mobile.ts`：16型行为依据、5–8题追问说明、严格结果schema及粘贴解析。
- `MobileEyes.tsx`：平台/方式选择、剪贴板失败时手动复制、结果预览、明确同意及导入。
- `POST /api/v1/ai-eyes/mobile-results`：沿用功能开关、来源校验、每浏览器/每IP频率限制；保存为完成任务。
- 无需数据库迁移，scope记录source=mobile_import/platform/basis；现有结果、删除、到期、导出及分享复用。
- 不签发执行和领取凭证。网站仅接收结构化概括，不上传粘贴原文；保留30天，清除Cookie可能失去访问权限。
- 手机应用实际输出不保证稳定：格式错误时保留输入并说明修正方法。未在第三方应用真实账号内替用户发消息。
