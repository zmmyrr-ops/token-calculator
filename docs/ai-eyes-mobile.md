# AI眼里的你：并列入口与行为统计匹配

## 用户流程
首页头部同时展示Codex和豆包/DeepSeek两张等宽入口卡片，手机上同样并排。选择后展开对应流程，切换不丢失已粘贴文本。Codex继续使用本机历史执行方式。

手机入口：复制通用指令 → 在常用AI里统计可见行为 → 复制JSON → 本站后台匹配人格 → 保存封面。指令不含任何人格名称、类型ID、16型清单或匹配权重。第三方AI不负责选择人格。

## 行为协议v2
`AI_EYES_BEHAVIOR_2`仅含format、basis、sample_count、keywords。keywords项为固定行为词keyword及整数count。可用词包括简短指令、完整需求、反复迭代、审美表达、追问依据等20项。

以用户消息为计数单位：每条消息同一词最多一次，可包含多个不同词，因此总次数可以超过样本数。对话至少3条、问答至少5条，最多50条；至少2种不重复词，单项次数不得超过样本数。无依据需追问，不能编造。接口拒绝额外字段、未知词、重复词、非法计数及客户端persona_id。旧版结果码需要重新使用新版指令；已保存旧画像不受影响。

## 后台匹配
`backend/src/ai-eyes-mobile-match.ts`独立维护16型的行为权重，按出现次数除以样本数归一化后加权。最高分作为结果；同分用类型ID稳定排序，不宣称置信概率或心理测量效度。规则版本behavior-rules-1随结果保存。统计说明由服务器根据出现最多的两个关键词生成，不采纳客户端自由文本。

`POST /api/v1/ai-eyes/mobile-results`复用功能开关、Origin、Cookie隔离、用户/IP频率限制及30天到期策略。数据库无需迁移：scope记录来源、依据、平台、样本数、规则版本，result沿用原有格式。仅保存最终类型、统计概括和来源元数据，不存原始聊天及完整关键词列表。分享不公开统计概括。

前端shared协议与指令不包含后端匹配表；前端仍有供报告渲染的既有文案资源，不能将本功能宣称为对所有技术用户保密的类型库。
