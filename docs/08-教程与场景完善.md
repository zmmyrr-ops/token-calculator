# AI 门道：教程实践与应用场景完善

2026-09-17。围绕已有五条路线深化内容，未以虚构课程、评分、学习人数或价格填充栏目。

## 已实现

- 教程列表提供搜索、场景与基础要求筛选，可通过 URL 保留条件；无匹配时可清除筛选。卡片显示目标成果、适用人群、阶段及交付数。
- 游戏、3D、视频、图像工作流、办公自动化五个场景提供成果导向入口、准备条件、阶段验收、配套工具职责与交付清单；关联实际教程与预算工具。
- 五篇实践内容各补充四个阶段，每阶段三项操作与一个验收条件；共 60 项操作、20 项阶段验收。
- 每篇包含准备清单、适用人群、交付内容、三项常见故障排查、步骤锚点目录，以及可编辑/复制的提问模板。
- 可下载 Markdown 实践清单，包含准备、步骤、验收、交付和用户编辑的模板。模板不上传；复制失败提供手动复制提示。
- 保留原四阶段内容顺序与进度存储结构，既有收藏及勾选进度继续生效。
- 补充 Godot、ComfyUI、n8n 官方参考链接，保留既有平台来源。内容为编辑整理的操作路线，不宣称已在所有软件/套餐上实测。

## 实现位置

`backend/src/content/practices.ts` 保存结构化实践内容，通过现有内容 API 提供；`shared/practice.ts` 定义协议。教程组件与场景页只消费 API 数据，未引入 SSR。搜索筛选在浏览器处理，生成清单也在本机完成。

## 验证

检查结构化内容的阶段数量、场景与工具引用，新增教程筛选/空态、场景跳转、排错展开、编辑模板和清单下载的桌面/移动浏览器验证。截图位于 `docs/screenshots/practice-*`。

验收结果：类型、lint、目录校验、生产构建及 58 项单测通过；20 项浏览器用例通过（品牌文案使旧“正文不存在”断言误匹配 meta description，修正为检查 H1 后复测通过）。四个代表路由在 1440/375px 下无横向溢出及脚本异常。
