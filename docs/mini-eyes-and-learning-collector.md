# 小程序 AI 画像与学习中心自动采集

## 小程序入口及使用

导入 `miniprogram/`（AppID wx30d01d25ba6ff5c3），工具页 → AI眼里的你。支持豆包、DeepSeek及其他AI：复制行为统计指令 → 发送到AI并完成必要问答 → 粘贴JSON → 微信登录后确认提交 → 查看自己的画像与封面。

指令和解析器由shared/ai-eyes-mobile.ts打包，和网站共用v2行为协议；不包含人格列表与匹配权重。服务端复用相同规则，返回自己的单一类型。分享只带测试入口，不带用户结果或统计。无后台模型API费用。

登录沿用已有微信OpenID关联账号。每账号保存最新一份结果30天，重新生成替换旧结果，支持主动删除；到期由小时清理任务及访问时清理。原始JSON及聊天不持久化，只保存匹配结果、统计概括、平台和依据。数据库备份按现有最长14天策略轮换，删除在线结果不会召回相册图片。小程序隐私说明已更新。

- `GET/POST/DELETE /api/mini/community/eyes`：仅native Bearer会话，拒绝网页Origin；POST每账号每小时最多6次，要求明确确认并遵守AI眼里的你功能开关。
- 表 `mini_eyes_results`：user_id唯一、payload、expires。与网页版匿名任务隔离。
- 封面复用已上线插画PNG，不在主包打入16张大图。点击保存时才请求相册权限。
- 微信后台需将 `https://ruming.top` 同时设为request和downloadFile合法域名；图片预览可以长按保存。
- 不会自动代替用户完成小程序平台上传、审核、隐私申报；应如实说明画像、剪贴板写入和保存图片等功能。

## 学习中心

网站和小程序的学习分类增加“精选分享”。每条内容保留标题、发布方、可取得的作者、原文日期、语言、原文链接、最多200字符的订阅摘要，以及本站编写的阅读建议。正文在原站阅读，不复制全文或绕过登录。当前接入科学空间、Hugging Face、Lil’Log和Simon Willison的公开RSS/Atom。

URL规范化去重；不覆盖人工编辑；已下架/删除条目保留去重记录，不再抓回。仅接受来源白名单下的HTTPS文章链接，禁止重定向、XML实体声明、超过4MB的订阅响应，单来源15秒超时。来源失败独立记录，不清空已有文章。每轮每源最多10条新内容，总计最多500条仍在内容库的自动索引；删除旧索引后可释放容量。

内容进入现有documents表，原有内容管理即可修改或下架。curation字段记录来源。learning_imports用于去重及删除后防止复活；learning_collect_lock用于跨进程租约，防止手动脚本与定时任务重叠。

## 定时与后台

后台新增“知识采集”：查看来源、收录数、最近执行时间、每源新增/跳过/失败；立即采集、暂停/开启定时任务。

Node服务每分钟检查是否到期，首次启动或距上次运行6小时执行一轮。服务重启后继续读取数据库中的执行时间，暂停状态同样持久化。调度运行在现有ECS容器，不依赖个人电脑或Codex在线。`LEARNING_SYNC=off`禁用自动调度（CI使用），不禁用明确触发的手动脚本。

手动运行：

```sh
# 本地：必须使用已初始化的同一个数据库路径
DATABASE_FILE=/绝对路径/mendao.sqlite npm run learning:sync
# ECS正式容器：复用其数据库环境变量和运行用户
 docker exec mendao-production-backend-1 node backend/dist/sync-learning.mjs
```

无需增加系统cron以免双重调度。每次运行状态持久化在learningLast，失败原因可在后台查看。结果反馈应区分“定时采集正常”与单个外部源暂时不可达。

## 微信生成按钮修复（2026-09-19）

微信环境中的动态函数执行限制使Zod的JIT校验返回“L is not a function”，随后被转换成格式错误。共享统计解析显式使用jitless校验，验证规则保持不变；客户端回归直接加载小程序真实构建产物，模拟微信Function受限行为。修复前回归失败，修复后及微信模拟器点击流程通过。

生成按钮只在请求处理中禁用。空内容、未确认、格式错误、网络失败显示弹窗和按钮旁说明；失败保留输入，恢复可重试状态。自动化可执行 `node scripts/test-miniprogram.mjs --eyes-only`，使用临时项目、隔离数据库，结束后重新打开正式miniprogram项目。更新体验版需重新编译预览，线上版本需重新上传发布。
