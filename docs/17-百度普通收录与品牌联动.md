# 百度普通收录与品牌联动

## 品牌

首页和资讯页统一使用「看懂 AI，用出门道。」。站点图标采用 AI 字母、节点连线和薄荷绿/紫色渐变，首页轨道与资讯页右侧视觉复用相同 SVG。favicon 使用 v3 缓存版本。

## 管理入口与操作

管理后台 → 百度收录。支持 API 推送、Sitemap 地址、手动提交链接清单下载。

1. 在百度搜索资源平台添加并验证 `https://ruming.top`。现有 www 验证文件仍可访问，但 www 页面跳转到主域，不能将 www 接口直接用于主域链接。
2. 从该站点「普通收录 → API 提交」复制完整接口调用地址，在后台粘贴保存。地址包含 token，不要提交到 Git、聊天或公开日志。
3. 设置单批数量（1–100）、每日本地预算（1–10000，按请求链接数计）。可先点击「立即推送一批」检查百度结果，再开启自动推送。
4. 自动模式只在 APP_ENV=production 生效，每 15 分钟检查新增/更新页面。部署重启后也会检查。测试环境不会产生外部提交。
5. 百度接收成功不等于收录；收录情况仍需在百度平台查看。Sitemap 和手动提交需在百度平台填写地址或粘贴链接清单。

## 数据与安全

SQLite 新增 `baidu_queue`、`baidu_runs`，迁移版本 4。队列保存公开 URL、内容指纹、状态、重试次数、最近接收时间；日志保留最近 500 次。每日请求预算和百度剩余额度独立存于 meta，不受日志清理影响。

状态：pending 待提交、sending 提交中、sent 百度接收、failed 明确失败、uncertain 结果未知。失败最多自动尝试 5 次，指数退避；超时或无法判定具体链接的部分成功需人工核对后重新排队。服务在发送中重启会标记 uncertain，避免盲目重复提交。

只允许百度官方 data.zz.baidu.com/urls 接口，拒绝重定向及域名/站点参数不匹配；保留百度提供的 HTTP/HTTPS 协议，不绕过 TLS 校验。接口响应限制 64 KiB，超时 15 秒。后台接口复用管理员登录及 Origin 校验。

凭据位于数据库同目录 `baidu-config.json`，权限 0600，原子写入，不回传到浏览器、不进入 SQLite 日志。生产路径通常为 `/opt/mendao/production/storage/baidu-config.json`，由容器运行用户读取。常规数据库备份不包含该凭据文件，需另行安全备份或从百度后台重新获取；不要复制到测试环境。

公开链接包含已发布知识、平台、模型及公共聚合页；不包含管理后台、账户、社区私人内容、重定向旧路由或外部资讯原文。Sitemap 与 API 采用同一公开链接集合。

## 构建与发布

沿用 `npm run check`、`npm run build` 和 GitHub Actions → ECS 测试环境 → 指定同一提交 SHA 晋级生产的流程。数据库为增量建表，无破坏性迁移。部署后登录后台验证队列，再配置接口。回退旧程序时可保留新增表；若需停止推送，先关闭自动模式。

## 验收

- ✅ 域名与接口白名单、凭据不回传测试
- ✅ 全量成功、部分成功、网络结果未知、额度与测试环境隔离测试
- ✅ 公开链接筛选与未变更页面去重
- ✅ 首页/资讯页 slogan 与 AI 图标统一
- ✅ 后台配置、链接分页、日志与清单下载
- 配置实际主域 token 后，检查第一批真实百度返回结果；当前 www token 不用于主域推送。
