# 我的 AI 工作台与场景任务包

## 用户功能

- `/workspace`：账号下的任务概览、提示词库、云端收藏、分类与备注、搜索和类型过滤。
- `/task-packs`：游戏角色、3D资产、30秒短视频、游戏宣传图4套任务包，共16个步骤。
- 每个任务包有交付目标、准备事项、关联工具与教程、操作步骤、完成标准、可复制提示词。
- 登录后开始任务，保存步骤进度、制作笔记、成果复盘、作品链接与一张私密预览图；支持重新打开、继续、删除。
- 提示词支持新建、编辑、复制、分类、查看历史、选取旧版本后另存新版本与删除。
- 登录后的知识、教程、工具、模型收藏进入云端工作台；人格配置、主动公开的AI画像、预算记录也可主动保存。
- 本机旧收藏仍保留，工作台可主动合并导入；不会自动上传浏览器旧数据。旧教程勾选记录仍保存在本机，不假装转换成新任务进度。
- 社区交流按钮只把任务名、成果复盘和作品链接写入当前浏览器的一次性草稿。用户必须在发帖页确认发布；私密笔记和图片不进入草稿。
- 工作台可导出全部资料，包含提示词历史及项目预览图。

## 数据与接口

复用网站账号的 HttpOnly Cookie。所有工作台接口放在 `/api/community/workspace`，继承现有来源校验与会话有效性检查；不开放小程序 bearer 路由。

SQLite新增4张表（幂等初始化，无需修改既有数据）：

- `workspace_items`：用户、内部链接、标题、类型、分类、备注、更新时间。`(user_id,href)`唯一。
- `workspace_prompts`：用户、当前内容、revision、更新时间。
- `workspace_prompt_versions`：提示词ID、revision、历史内容、创建时间。删除提示词时删除历史。
- `workspace_projects`：用户、任务包完整版本快照、项目进度及笔记成果、revision、更新时间。

任务包定义在 `shared/task-packs.ts`。创建项目时固定任务包快照，日后修改模板不会改变用户已开始项目的步骤含义。工作台概览不返回项目图片、完整笔记或提示词正文。

公开读：`GET /packs`、`GET /packs/:id`。

登录后：`GET /`（轻量概览）、`GET /items?q=&kind=&page=`（每页24条，服务端搜索）、`POST /items`、`PATCH /items/:id`、`DELETE /items/:id`；提示词 `POST /prompts`、`GET/PUT/DELETE /prompts/:id`、`GET /prompts/:id/versions`；任务 `POST /projects`、`GET/PUT/DELETE /projects/:id`；备份 `GET /export`。

提示词与任务更新必须携带当前revision，冲突返回409，不静默覆盖另一个页面的修改。所有对象读写根据会话中的用户ID查找，客户端不提交owner。工作台页面noindex，公开任务包可被索引。

## 资源限制与隐私

每个账号最多500条收藏、100条提示词、30个项目；每条提示词最多50个历史版本，每版最多20000字符。笔记最多10000字符，复盘最多6000字符。

预览图在浏览器转成最大512px PNG，服务端校验PNG格式、尺寸和最大256KB。原始视频、模型和工程文件不托管，可使用作品链接。项目图片仅随私有项目详情返回，不设公开文件URL。

计算器正文不上传；只有主动点击保存预算时，才发送词元数量、编码、币种和费用情景（不含输入原文）。旧本机收藏导入由用户主动触发，重复项保留云端已有分类和备注。

## 开发与发布

前端：`frontend/src/workspace/Workspace.tsx`、`workspace.css`。后端：`backend/src/workspace.ts`。初始化在 `initCommunity()` 中执行，路由挂载在cookie社区路由内，避免改变既有cookie路径。

任务包SEO由 `shared/seo.ts` 与 `backend/src/prerender.ts` 接入；开发预览代理支持两个新路由。数据库现有整库备份覆盖所有新增表。

验证命令：`npm run check`、`npm run build`、`npm run test:e2e`。单元测试覆盖跨账号隔离、来源校验、失效会话、revision冲突、历史保留、非法步骤及上传、删除与导出。浏览器测试覆盖注册后开始任务、保存及重开、提示词版本、云端收藏、备注、导出和不带私密笔记的社区草稿。
