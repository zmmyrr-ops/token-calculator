# 公开页面预渲染与百度接通

## 修复的问题

原站点首次响应只有 React 空壳，正文、标题和 canonical 依赖浏览器运行 JavaScript。百度推送模块已开发，但此前生产环境没有主域接口配置及实际提交记录。

## 实现方式

保留 React 前端、Node API 和独立容器。在启动及已发布内容变化后，从 SQLite 的 published 数据预生成公开 HTML 缓存，请求到来时直接取缓存。不是每次请求执行 React SSR，也不按 User-Agent 区分访客和爬虫。

- 知识文章含正文、实践步骤、视频原站入口与来源。
- 模型、工具及场景页含其实际资料、限制、来源与内部链接。
- 首页和学习中心提供公开内容链接；模型与资讯列表提供真实分页链接。
- 每页独立 title、description、canonical、robots 和 JSON-LD。
- 首页包含品牌写法 AI门道 / AI 门道；结构化数据不代表获得富结果或排名。
- CMS 发布/撤下和资讯持久化后，事务完成的 microtask 中刷新整个缓存；未发布草稿不进入 HTML。刷新完成原子替换缓存。
- React 加载期间保留首屏预生成内容，内容接口就绪后接管；客户端导航继续更新 SEO 元信息。
- 后台、账号、搜索、筛选、社区页面 noindex；不存在或超出分页范围的公开页返回 404。旧教程/场景入口 308 到对应学习中心筛选。
- 用户编辑的内容经过 HTML 转义；不将 API 凭据、账号数据或完整 bootstrap 嵌入公开页面。

缓存在内存中，随后端进程重启重新生成；内容源仍是数据库，不新增第二份可编辑内容。Nginx 提供 JS/CSS/图片等静态文件，公开文档请求转发到 Node 的预生成页面服务。构建产物中的主站/测试站 index.html 同步复制进后端镜像，用于注入正文且保留正确的资源版本。测试环境保留 /staging 前缀并 noindex。

## 百度普通收录

主域接口必须绑定 https://ruming.top。凭据只保存在生产 storage/baidu-config.json（0600），不进入 Git、日志或前端。先上线可抓取 HTML，再配置接口并检查真实回执。自动提交每 15 分钟检查，遵守本地预算与百度返回配额。

验证文件证明站点归属；API 返回 success 表示接收，不代表已抓取、已收录或品牌词排名。百度索引量与抓取诊断需在该站点的搜索资源平台查看。

## 验证与部署

新增单元测试覆盖真实正文、独立元信息、分页、发布刷新、草稿隔离、撤下 404、测试站前缀、noindex 和内容注入防护。浏览器新增禁用 JavaScript 阅读文章测试。沿用 GitHub Actions 全量检查、隔离浏览器测试、ECS staging 验证及同 SHA 晋级 production 流程。

回退时需同时回退前后端镜像，避免 HTML shell 与资源版本不一致。数据库结构没有破坏性变化。

- 正式版本：`25fe543197a93b47765f4a409faa5d5e43c952d0`；CI `35213570247` 全部通过，88 项单元测试、34 项浏览器测试。
- Staging 与 production 均完成 1280px/390px 无 JavaScript 阅读、模型分页、无横向溢出、相同爬虫/普通 HTML、404 及 React 接管检查。
- HTTPS 主域接口已配置到生产，自动推送开启，每批 10 条、本地每日上限 100；实际以百度剩余额度为准。
- 首批真实回执：requested=10、success=10、remain=0。首页 https://ruming.top/ 状态为 sent。此处 sent 仅代表百度接收。
- 剩余链接保留待提交状态，次日检查额度后继续。资料更新会重新入队，因此当前 sent 计数可能小于历史 success 累计。
- 服务器重启后健康检查 ready，文章正文仍出现在初始 HTML。

百度搜索资源平台的索引量、抓取诊断和最终搜索展示仍需后续观察；本次没有宣称已经收录或保证排名。
