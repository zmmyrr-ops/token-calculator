# 列表分页与首屏优化

2026-09-17

模型目录每页请求 24 条；全站搜索、工具目录、知识文章每页请求 18 条。筛选由服务端执行后计算总数，再返回当前页。资讯沿用原有后端分页。教程和场景页本次保持现有交互。

## API

- `GET /api/v1/catalog?page=1&pageSize=24&q=&provider=&access=&support=`：模型列表，返回 models、total、page、pageSize。
- `GET /api/v1/search?page=1&pageSize=18&q=&type=`：跨知识、工具、场景和模型搜索，返回 items、total、page、pageSize。
- `GET /api/v1/library/tools?page=1&pageSize=18&q=&category=`：工具摘要列表，附完整分类选项。
- `GET /api/v1/library/learn?page=1&pageSize=18&q=&category=`：知识摘要列表，附完整分类选项，不传输正文。
- 页码限正整数 1–100000，每页 1–100 条，关键词最多 200 字符。非法参数返回 400；超出结果范围返回空列表，可返回上一页或重置筛选。

`bootstrap?path=/当前路径` 返回页面初始化数据。模型列表不再包含全部模型；模型详情只返回该模型；计算器返回初始的三个参考模型，添加模型沿用搜索接口。独立的 modelCount 保留完整目录统计。覆盖审计的逐条明细不再进入页面初始化包。无 path 的原接口保留兼容旧客户端，数据库、CMS 与 sitemap 仍读取完整内容。

翻页 URL 保留筛选条件，可分享、刷新和前进/后退。异步请求具有加载、失败重试与空结果状态，取消过期请求，避免快速切页时旧响应覆盖新页。

## 验证与边界

65 项单元测试、类型检查、lint、目录检查、生产构建通过。生产构建下桌面与手机的 22 项相关浏览器用例通过，含页间无重复、详情读取、非法参数、空结果、翻页后退、搜索、计算器及 SEO 回归。

本地同一份真实内容测量的未压缩初始化 JSON：首页约 37 KB，模型目录/资讯页约 4.2 KB，原接口约 404 KB。ECS 已为 bootstrap 启用 gzip；实际网络耗时随网络变化。

分页目前在 Node 层读取已发布内容并筛选切片，解决客户端全量传输问题；尚未改为 SQL LIMIT/OFFSET，也未实现全文索引。内容规模进一步增长时，应增加数据库查询层与索引。首页仍包含现有文章、工具与场景内容，前端代码分包不在本次变更内。
