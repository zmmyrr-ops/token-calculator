# 小程序单页导航与精简模式发布记录

应用版本：`7461c131c727414c86786cdece06276ce8c7b6d8`。
CI：https://github.com/zmmyrr-ops/token-calculator/actions/runs/35237097615 。全部检查、构建、浏览器测试成功；测试环境验证后，同一镜像已提升至生产环境。

## 使用方式

后台 → 小程序设置 → 精简模式 → 保存。生产和测试环境均已开启。该配置对所有用户一致，不判断审核身份，也不按审核进度自动改变。

首页是 `pages/home/index`，资讯、学习、工具、我的使用内容组件和页面内底部按钮切换；`app.json` 不配置 `tabBar`。详情、账号和计算器仍为正常子页面。

精简模式统一关闭资讯、社区、模型库、平台导航。底部只显示学习、工具、我的；工具区域保留 Token 费用预算及对应网页版计算器链接。收藏过滤已关闭模块，深层链接退出至工具区域；模型库和平台导航使用独立小程序浏览接口并执行服务端开关检查。网站原内容和接口不受影响。

取消精简模式时恢复各模块单独配置的开放状态；已有内容不删除。
