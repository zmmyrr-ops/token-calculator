# 匿名埋点与统计后台

2026-09-17。后台顶部选择“数据埋点”，可查看最近 7、30、90 天的访问 PV、入口点击、计算器使用、全部事件、每日趋势、热门页面及主要入口。点击刷新统计读取最新数据库汇总；当前不自动轮询。

## 事件范围

- page_view：公开 SPA 首次进入及 pathname/search 变化，不跟踪 hash 滚动。不要求所有页面数据已加载成功；属于访问尝试。
- navigation_click：公开页面 header 内链接点击。
- content_click：正文、卡片、分页等站内链接点击；目标记录路由类型。
- outbound_click：资讯原文、工具官网、模型来源等 HTTP(S) 外链点击，只记录 external，不存外部 URL。
- search_submit：首页、搜索、模型、工具、知识、资讯页面提交表单；不存关键词。使用即时筛选且未触发表单提交的操作不算该事件。
- calculator_used：每次进入词元计算页面，首次成功完成非空文本计数时记录一次；后续输入不重复累计。
- report_export：成功触发词元计算报告导出时记录，不包括剪贴板复制。

点击是点击意图，不代表第三方页面成功打开。链接下载与 mailto/blob 不记录。后台路由不挂载埋点；来源页面和目标页面均不记录 admin。详情页面合并为 /models/:id、/tools/:id、/learn/:id、/scenarios/:id，所以热门页面显示页面类型，不提供具体文章排名。

## 数据与接口

POST `/api/v1/events` 接收 `{id,name,page,target}`，id 为每事件随机 UUID，用于重复上报去重，并非访客 ID。严格字段和枚举校验，拒绝额外字段；不存 query/hash、用户输入、IP、浏览器指纹、账号或可跨会话关联的标识。事件时间由服务器生成。

上报需要允许的 Origin，单请求 JSON 最大 2 KB，单后端实例全局每分钟最多处理 1000 个同源提交尝试，超额 429。来源校验不能证明真实访客，自动化访问仍可能进入统计；不用于财务计费或精确人数测量。上报 fetch 使用 keepalive，生产请求不携带 Cookie；测试请求允许同源凭据以通过测试站 HTTP Basic 认证，后端不读取或记录这些凭据；失败静默，不影响主功能，不持久化待发送队列。

GET `/api/admin/analytics?days=7` 经管理员鉴权和首次改密要求后读取汇总，days 仅允许 7、30、90。返回 totalEvents、pageViews、clicks、daily、events、pages、targets，所有日期按北京时间（UTC+8）统计，包含当日。PV 为访问次数，非 UV；不提供独立访客或停留时间。

测试环境使用 `/staging/api/...`，仍写测试库；两个环境的数据不混用。

## 数据库与生命周期

启动时执行幂等的新增表与索引，登记 migration 2；保留既有 documents/admins 等表。新增 analytics_events 表（seq、event_id、name、page、target、at），event_id 唯一，索引 at 与 (name,at)。发布前原有备份流程不变，新备份也包含埋点。

服务启动、每接收 100 次有效事件、查看统计时清理：删除超过 90 天及最早的超额记录，约保留 100000 条，批次间最多临时超过 99 条。高流量时记录可能不足 90 天；空闲时在下次启动/读取/写入清理。SQLite 清理行不保证立即缩小数据库文件，磁盘紧张时按运维流程处理，勿在线随意替换文件。

上线前无历史埋点，空状态和趋势中的零值表示没有记录，不用测试数据填充。自动化冒烟访问可能产生少量真实请求事件，应结合访问量理解。

## 用户控制与验证

隐私页提供“允许匿名访问与功能使用统计”开关，关闭后停止后续上报；遵循浏览器 doNotTrack=1。偏好仅存当前浏览器，测试与生产使用不同 key。关闭不会追溯删除已匿名化的事件，因为没有访客标识可定位个人记录。localStorage 不可用时默认停止统计。

测试覆盖：字段最小化、私密查询不进入事件、同源拒绝、2KB 大小限制、去重、北京时间边界、过期清理、未登录拒绝统计、后台空态/有数据刷新、7/30 天切换、手机布局及禁用上报。测试数据只在隔离测试库中使用。
