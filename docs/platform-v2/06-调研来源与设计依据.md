# 调研来源与设计依据

检索日期：2026-09-17。以下为本轮阅读到的公开官方资料；价格、区域、权限、质量与所有当前型号没有在本轮穷尽审核。没有调用付费生成服务，也没有下载厂商作品来充当本站案例。

## 产品形态参照

- [Futurepedia](https://www.futurepedia.io/) 已提供工具发现与学习内容。因此本项目把任务交付、步骤衔接和可追溯的费用作为设计重点。这是根据其公开页面作出的产品判断，不代表完成所有竞品评测；不引用其用户规模作为本项目机会证明。
- [Ludo 官方文档](https://ludo.ai/docs) 展示游戏策划和素材辅助能力，并说明其不能直接生成完整可玩游戏。本项目据此避免把“辅助策划/素材”写成“一键交付游戏”。

## 首期候选工具能力

- [Scenario 介绍](https://help.scenario.com/articles/3401611429-introduction-to-scenario)：官方描述覆盖创作资产和风格控制。作为游戏资产阶段候选；本轮没有验证具体素材质量或套餐。
- [Meshy 产品与价格页](https://www.meshy.ai/pricing)：文本/图片生成 3D 与纹理相关能力；计费与套餐应单独建模。本轮未录入实时金额。
- [Tripo 自动绑定](https://www.tripo3d.ai/features/ai-auto-rigging)：提供自动绑定介绍与导出工作流说明；实际骨骼、权重和导入结果需案例验证，不能照搬“生产可用”的营销措辞。
- [Tripo 开发者文档](https://developers.tripo3d.ai/)：展示 3D 生成 API；说明同一平台可以同时有网页和 API offering，不能混为一种收费入口。
- [Blender 建模功能](https://www.blender.org/features/modeling/)：支持网格编辑与 UV 等操作，作为非 AI 配套工具纳入修整步骤。
- [Runway 生成视频入门](https://help.runwayml.com/hc/en-us/articles/37425232841875-Getting-Started-with-Generative-Video)：有多种模型和创作入口。用于说明平台、模型和操作方式需要分开管理；不以本页证明全部地区与所有套餐可用。
- [即梦视频生成介绍](https://jimeng.jianying.com/tools/ai-video-generator)：包含文字与图片生成视频入口，可用额度与参数要看账号内规则。用于中文视频场景候选；不据此断言统一秒价或一律商用。
- [ElevenLabs 音效文档](https://elevenlabs.io/docs/eleven-creative/playground/sound-effects)：介绍文字生成音效；作为音效阶段候选，实际费用按其具体服务口径核验。

可灵、海螺、Veo、Sora、Adobe Firefly、腾讯混元 3D、Hunyuan 系列、开源 3D / 视频模型，以及游戏引擎/编程助手等，列入下一轮目录审计候选池。此处只是收录调查范围，**不是已验证的当前版本或推荐榜单**。保留全量中高端模型目标，利用覆盖台账逐项推进。

## 工程依据

- [Next.js 自托管指南](https://nextjs.org/docs/app/guides/self-hosting)：自托管及缓存/多实例协调。设计使用数据缓存与按请求 SSR，继续保持 nonce 一致性。
- [Payload 安装](https://payloadcms.com/docs/getting-started/installation)、[生产部署](https://payloadcms.com/docs/production/deployment)：其可与 Next.js 集成，仍须对项目的具体依赖版本做兼容 POC。

## 事实与方案的边界

官方链接支持的是相应功能存在或官方如何描述它们；工作流顺序、首发规模、技术组合、预算公式应用和商业定价是本项目设计。使用“候选”不代表实测优胜。

本项目所有价格示例都是明确标注的演算假设。实际商业使用权限、地域和用户协议应在发布具体档案时按版本/套餐核验；本轮没有给出法律适用结论。

来源更新策略、评测流程与维护周期是计划，没有创建自动化任务或对外订阅。工具列表并非只能收录上述品牌，也不代表已经覆盖全部创作服务。
