# 商业模式与实施清单

## 1. 商业路径

建议先靠免费知识和工具建立信任，再围绕持续维护的路线、项目组织和团队复用收费。用户愿意为什么付费需要访谈验证；平台数量多不等于有付费理由。

**免费层**：全部公开工具/模型基础资料、核心知识、来源与时效、基础路线、token 计算、基本比较和本机收藏。纠错与关键条款不能被付费墙遮住。

**个人会员（P1）**：跨设备项目路线、路线版本变更提醒、较完整的项目模板、实际案例拆解、多个项目预算情景。会员付费买的是持续维护和组织效率，不是获得未经解释的“最优模型”。

**专题产品（P1）**：例如「完成第一个游戏原型」「产品短片工作流包」，按明确交付物单次付费；包含示范工程、模板与一段明确期限的版本维护。必须先实际跑通路线和确认示范素材可以分发。

**团队服务（P2）**：私有工具库、采购对比、内部流程和培训。初期可作为人工服务验证需求，避免马上做复杂多租户 SaaS。

**联盟与赞助（可选）**：官方有合作计划才接入；明确标注联盟链接和赞助位。付费不改变自然推荐与实测结论，不出售“最佳工具”标签。没有真实合作时不得写“合作伙伴”。

不建议初期采购大量生成额度再转售：这会增加账单、服务质量和售后负担，与知识平台首发核心价值不同。

## 2. 定价与经济模型：待验证假设

用于访谈的测试区间：个人会员 ¥19～39/月；专题包 ¥59～199/次；团队服务单独评估范围后报价。这些是本项目定价假设，不是市场平均价，也不是已上线套餐。

月经营结余的简化口径：会员实收 + 专题实收 + 其他净收入 − 退款 − 支付手续费 − 云服务/邮件/存储 − 内容制作与维护 − 获客与支持成本。税务和实际收款处理需上线前按经营主体确认。

**示例，非收入预测**：100 名付费用户 × ¥29/月 = ¥2,900 毛收入。若工具基础成本假设 ¥500、内容维护 40 小时 × ¥100 = ¥4,000，则尚未计支付/退款/获客就已经不覆盖成本。不能因为 token 调用少就推断利润高。

用保守留存观察回收周期：统计每个付费 cohort 的实收、退款、直接服务成本与累计贡献，不用一次访问到付费的转化率推算终身价值。免费知识内容的维护工时必须计入经营判断。

首发可以无付费。付款模块上线门槛：至少 10 次目标用户访谈、明确需要反复使用的功能、有可交付的付费内容、售后与退款流程、服务条款和收款主体就绪。测试报价不能直接变成自动扣费授权。

## 3. 内容获客与留存

- 围绕具体成果写搜索页面：图片做成游戏道具、AI 生成精灵图怎样导入、30 秒视频要生成多少素材。
- 一个实际案例拆成路线、知识点、失败排查和预算样本，互相链接；不生成大量近似 AI 文章抢关键词。
- 用户自愿订阅相关路线更新；只有版本变化影响操作、价格或可用性才提醒，发送前取得订阅授权。
- 在创作者使用的平台发布有用的过程展示，链接完整路线；发布行为由用户另行安排，本次不会自动发帖或联系他人。
- 持续记录搜索无结果和纠错类别，不采集私人全文；用来调整内容优先级。

## 4. 实施阶段与资源

计划基于 1 名熟悉 Next.js 的工程师 + 兼职领域编辑可并行配合；以下是规划估算，受 CMS 兼容与内容测试影响。

- **M0 设计确认与 POC：4～6 工程日**。验证 CMS/数据库、选取三条实测任务、确认 ECS 条件。
- **M1 内容基础与迁移：10～14 工程日**。后台、schema、模型导入、来源、发布流程和基础目录页。
- **M2 用户闭环：14～18 工程日**。场景、选型、工作流、知识、比较、预算和收藏。
- **M3 验收与试运行：8～12 工程日**。内容导入、检索调优、权限、回归、ECS 发布与小范围用户试用。
- **合计：36～50 工程日，约 8～10 工作周**，不包含不可预测的等待。内容另预留约 80～140 编辑/测试小时，属于首发库存的初步估算。
- 单人同时承担工程、编辑与运营时，内容时间应叠加，不能仍承诺上述并行日程。首次 3 条路线试做后重新估算实际生产速度。

MVP 首发门槛：3 个场景、24 个任务、24 个唯一深度工具档案、12 条路线、36 篇知识和9个小范围实测；若维护能力不足，可以先发布 3 条已跑通路线的小范围预览，明确叫内测，不能把库存目标改成“已完成”。

P1：登录同步、作品/项目管理、专题付费、更新订阅、有引用问答。P2：团队空间、更多领域、经过验证的执行集成。各阶段以用户使用证据决定投入。
