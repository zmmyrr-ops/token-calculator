# AI 知识站｜技术方案 v5

2026-09-17，按用户新要求停止 SSR，拆分 React 前端与 Node.js 后端。原 SSR 设计仅保存在 `02-SSR历史技术方案.md`，不再用于当前实现。

## 模块与构建

采用 npm workspaces，共享一份锁文件；前后端独立 package、启动脚本与产物，避免页面和采集任务耦合。前端使用 Vite 8、React 19、React Router 7、TypeScript。后端使用 Node.js 24、Express 5、rss-parser，通过 esbuild 编译为 ESM；后端只提供 JSON、robots 和 sitemap，不生成页面 HTML。

- `frontend/src/pages` 保留原页面路径；`main.tsx` 明确声明路由；`content.tsx` 加载 API 内容，有加载、失败与重试状态。
- `frontend/src/components`、`workers` 实现本地计算、素材预算、本机收藏；不向后端发送计算正文。
- `backend/src/content` 和 data 仅作为首次建库种子；SQLite 存储正式内容、管理员、会话、历史和资讯。后台发布后经 API 交付前端。
- `shared` 存放类型、Zod 约束、Decimal 计价、收藏校验与资讯协议。共享内容类型只使用 TypeScript 类型导入，不把后端模块打入前端。
- 构建产物：`frontend/dist` 静态资源、`backend/dist/server.mjs` API。内容经管理后台发布，不需要重建前后端。

## 页面与 API

页面包括 `/`、`/learn` 及详情、`/models` 及详情、`/tools` 及详情、`/scenarios` 及详情、`/tutorials`、`/calculators`、`/calculators/tokens`、`/calculators/media`、`/compare`、`/saved`、`/search`、`/news`、`/updates`、`/about`、`/privacy`、`/how-it-works`。

- `GET /api/v1/bootstrap`：站点、目录、知识、工具、场景及覆盖记录，读取数据库已发布版本，no-store。
- `GET /api/v1/catalog`：q/provider/access/support/page/pageSize，pageSize≤100；返回版本、抓取时间、总数和当前页模型。
- `GET /api/v1/catalog/:id`：单模型，未找到返回 404。
- `GET /api/v1/news`：q/category/source/page/pageSize，默认 18 条；返回文章、总数、采集状态、轮询周期及来源状态。
- `GET /api/v1/news/sources`：来源配置及最近尝试/成功/错误/收录数。
- `GET /api/health/live`、`/api/health/ready`：进程与内容初始化状态；ready 的 news 字段单独反映来源状态，不把外站故障等同本站故障。
- `GET /robots.txt`、`/sitemap.xml`：可发现路由；正文仍为浏览器渲染。

分页与关键词长度验证；重复参数和未知资讯分类/来源返回 400。未知 API 返回 JSON 404。资讯接口不开放任意 URL 抓取或公共强制刷新，防止被调用者制造采集负载。生产浏览器和 API 同源，不开放通配 CORS。

## 资讯采集

首批源为量子位、Google AI、NVIDIA Blog、Hugging Face、Microsoft Research 的公开 RSS。每 15 分钟并行检查一次，同进程锁防重叠；页面每 60 秒刷新可见列表，手动刷新也仅获取本站已收录内容。

每源使用固定 URL、20 秒超时、5 MiB 响应上限、ETag / Last-Modified 条件请求；拒绝重定向、DOCTYPE/ENTITY，源错误隔离。只保存标题、HTTP(S) 原文地址、来源、自动分类、来源发布时间与首次收录时间。不转载正文、不生成摘要、不虚构热度或评分。标题移除标签；React 按普通文本显示。URL 去除追踪参数和片段后 SHA-256 去重；发布日期无效或明显未来时标记未知。分类按标题关键词与源默认分类，提供自动分类说明。

最多保留 3000 条，事务写入 SQLite，重启恢复。首次无内容显示等待采集，不填演示数据；部分/全部源失败保留历史并公开错误。只有历史文件不存在时初始化空库，损坏文件阻止启动，避免静默覆盖。单实例、单写入者；水平扩展前改用服务型共享数据库和独立调度任务。

## 现有功能兼容

两种本地参考分词编码继续使用版本固定的词表、SHA-256 校验与 Web Worker；1 MiB 限制、快速输入竞争处理、报告导出、私人报价与缓存/推理预算保持。原浏览器收藏 key 及进度结构不变，旧数据无需迁移。所有深层路由可直接打开和刷新，由 Nginx 回退到 index.html。

## 部署与安全

ECS 上宿主 Nginx 提供域名 HTTPS；前端 Nginx 容器提供静态资源和 API 反向代理；Node 后端容器仅在容器网络暴露 4000。资讯使用命名卷持久化。CSP 限制脚本、请求、Worker 来源；不启用外部脚本和跟踪。前端代码中只允许公开环境变量，不存服务器秘密。

本地以 Vite proxy 联调独立后端；生产遵循 `deploy/README.md`。当前没有 ECS 凭据和 Docker 环境，尚未完成云端构建/证书/网络验证。纯 SPA 的首屏依赖 JS 和内容 API，SEO 正文抓取和分享摘要较原 SSR 有所下降，已保留 noscript 提示及 sitemap。

## 验证

类型检查、ESLint、计价/编码/收藏/内容关系/资讯归一化单测；浏览器覆盖桌面与移动端，检查非 SSR 静态 HTML、API 校验、深层路径、词元输入不上传、收藏恢复、预算与比较、真实资讯检索/来源与空态。网络源通过真实请求验证，单测夹具不参与运行时内容。
