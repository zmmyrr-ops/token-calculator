# AI 眼里的你：接入 AI 门道的实现策略

日期：2026-09-18。此文件保留开发前的分析方案；实现现状与适配差异见 [开发文档](ai-eyes-development.md) 和 [交付清单](ai-eyes-todo.md)。依据用户提供的 v4.2 完整需求及 illustrated_persona_v1 海报模板，并检查现有 React / Express / SQLite、埋点及备份代码。

## 结论与产品边界

可作为平台独立功能开发。采用“用户自己的 Codex 匹配固定类型，网站展示原文”的架构。首个技术关卡是历史读取适配，不是生成文案。保留全部 16 型及开场、总览、段落、加粗与标点；不随机抽卡，不生成分数，不把娱乐台词当实际聊天统计。

现有 /personas 是“给 AI 选择说话风格”；新模块是“AI 如何看待我的使用习惯”，类型、内容版本、表和权限必须分开。建议入口 /ai-eyes，目录 /ai-eyes/types，任务 /ai-eyes/runs/:id，领取 /ai-eyes/claim，公开结果 /ai-eyes/s/:id；平台根首页不替换，首页和人格合集增加入口。API 使用 /api/v1/ai-eyes，图片用 /ai-eyes-art，避免页面代理与静态资源路径冲突。

## 优先验证：Codex 执行端

官方 App Server 文档提供 thread/list、thread/read；后者可不恢复旧会话地读取历史。分页轮次接口属于实验性能力。不能据此承诺所有桌面客户端、云任务、远程主机均能读到同一份历史。

1. 建立能力探测，只检测环境与协议支持；不先扫描用户聊天。明确 CLI 可用性、权限、CODEX_HOME、操作系统和客户端版本。
2. 在用户选择范围并授权后，优先适配官方读取接口。不使用 resume、fork、turn/start 去启动旧会话。thread/list 默认可能扫描日志并修复元数据：验证 useStateDbOnly 等参数及启动副作用，不能宣传“绝对零文件写入”。保证不改历史、项目及配置。
3. 显式校验来源筛选：列表默认来源不代表全部桌面历史。排除子代理、工具测试等来源；归档是否纳入应在界面说明。验证不了的版本明确不支持，文件解析仅作为有版本约束的兼容路径。
4. 按消息时间过滤，而不是仅按线程创建时间；旧线程最近的消息也可能在范围内。时间缺失时不猜测。固定时区、起止时间，限制 10 会话、每会话 15 条用户消息、共 20,000 个可见字符（非 Token 数）。
5. 先本地结构化清洗，再把样本交给当前模型。按稳定消息标识、分叉来源和内容去重，保留均衡会话样本。系统、工具、环境元数据不进入样本；用户消息中的引用、代码等用规则与模型辅助识别，不能保证自然语言来源识别百分百正确。
6. 本地样本与匹配说明不打印到工具日志；私有临时目录，退出清理。当前模型仍会接收清洗后的样本，当前执行会话也可能留存上下文；网站删除结果不能删除 Codex 中的这些记录。
7. 使用已固定版本的执行包、文件清单和哈希；先查看脚本再执行，不提供远程脚本管道直接执行命令。哈希防意外变动，不等同于独立可信签名。
8. 结果只回传合法类型 ID、可选不同备选、0–2 条不超过 48 可见字符的概括说明及样本范围；结构严格白名单。密钥/联系方式规则可拦截明显泄漏，但不能证明自然语言绝无机密，因此不确定时省略说明。

首个原型验收：用户创建范围任务 → 新会话按指令执行 → 仅回传小 JSON → 原页面自动恢复完整结果。覆盖无历史、缺权限、版本不支持、中断与网络失败。该原型通过之前不批量投入 16 张插画生产。此轮未读取或分析用户其他历史。

## 原文内容与数据库

从 USER_ORIGINAL_BEGIN / END 提取原稿，保留原始字节与 SHA-256。解析为受控 Markdown AST；保留源区间、顺序、段落及加粗，不执行 HTML。稳定块 ID 使用“内容版本 + 类型 + 顺序”。标题、关键词、气泡、金句通过源块引用，不另存手抄版本。

继续 SQLite，以 ai_eyes_ 前缀新增：catalog_versions、content_blocks、layout_versions、runs、results、selections、grants、shares、feedback。结果、选择与分享分别存储；公开分享是用户确认时的不可变快照引用，修改私密昵称或自选结果不静默改变已分享内容。重新发布明确创建新快照并撤销旧版，历史原推荐不覆盖。

用户无需登录，独立匿名会话 Cookie；现有用户系统不强行介入 MVP。现有后台身份与审计可以复用。原文编辑只支持显式导入新版本与差异预览，不能在普通表单里无声覆盖旧版本。

## 任务与凭证

run_id 是标识，不是权限。浏览器拥有查看/选择/删除权限；submit_token 只能读执行参数与写阶段/结果；claim_token 只能兑换查看权限。三种权限隔离，凭证随机生成并哈希存储。

创建后 30 分钟可提交，24 小时可领取；结果完成后 30 天过期。终态事务锁定，取消与提交竞态只允许一方成功。同一规范化结果哈希幂等确认，不同结果冲突。进度单向前进，客户端超时不能制造虚假阶段。网页 3 秒轮询，逐渐退避到 10 秒，终态停止。

领取片段令牌经 POST 一次兑换，随后 replaceState 清掉片段；GET 与链接预览不消费令牌。处理“服务端已兑换但响应丢失”时，原匿名会话可恢复，不能让一次网络错误永久丢结果。另一个设备领取是否保留原浏览器访问按明确多授权设计，不把领取等同于账号登录。

复制的执行指令本身含短期凭证，可能保留在剪贴板与 Codex 消息里；不能宣称凭证从未进入历史。接口只通过请求头提交，禁止放在 shell 参数、日志和请求 URL 中。私密路由及领取页禁用通用埋点，no-store、noindex、严格 Referrer-Policy；不能仅靠 robots.txt 保护。

原浏览器关闭后任务仍可完成。用户失去 Cookie 且领取链接过期、未绑定账号时无法保证恢复，UI 要明确。当前部署脚本保留 14 天同机备份；到期清理需覆盖在线数据和渲染缓存，备份按轮换清理。恢复旧备份时须先应用到期与删除记录，防止恢复已经撤销的公开链接。

## 海报与完整导出

先确认“一句话 CEO”插画方向，再画其余 15 型。采用成年卡通人物、几何切面、角色动作与道具；不复用刚做的 12 个语气头像。图像模型只负责人物插画，标题、原文气泡、金句、品牌及真二维码由模板绘制。文档所说“当前没有 image_gen”是旧环境记录，本会话已有图像生成能力，不需要据此要求 API Key。

页面：鲜明色的传播封面 + 奶油白全文阅读。首屏可看封面，正文默认展开。完整长图、多页和封面分别标注，不用封面冒充完整报告。

推荐浏览器本地导出，避免在当前 2 核 4GB ECS 上为每个用户启动 Chromium。先完成同源字体、插画、受控文本块的共享排版器；用字体实测宽度换行，生成分页布局树，逐页 Canvas 绘制 PNG。导出预览使用实际生成的图，避免预览与下载错位。

单页 1080×1440，边距至少 72px，字号以文档为起点，不为固定页数缩小正文。章节标题与下一段绑定，长段在行边界拆为连续片段。测试不仅比对块 ID，还要比对每块的字符区间完整覆盖，防止分页断行漏字或重字。

串行绘图、释放每页 Canvas，ZIP 打包并提供逐页保存。长图超过经过设备实测的安全预算时提供全套分段或多页；不写死跨浏览器统一最高像素。系统分享是增强项，能力检测不支持时仍能保存。下载无需先公开；私密图二维码指向模块入口，公开图指向分享全文。

昵称使用可见字符计数，最长 12；二维码须实机扫码。默认社交预览可使用预先构建的 16 型无昵称封面，避免每次动态渲染；公开页 HTML 输出对应元信息。分享页默认 noindex，静态目录页可做 SEO。

## 管理后台、统计与滥用控制

新增独立后台页：总开关、执行包支持版本、原稿版本与哈希、插画/模板版本、任务状态与错误码、公开分享撤销、清理情况、按阶段完成率。默认不展示个人匹配说明，运营不需要读取它。

埋点复用现有基础设施但扩展白名单：创建、复制、真实执行、完成、章节到达、封面保存、长图保存、全套多页成功、分享创建和撤销。领取页不装统计。公开分享转化可用随机归因标识，不发送领取凭证、昵称或原始路径参数。

匿名任务需按匿名会话及可信代理来源 IP 限流，限制未完成任务数量和响应体。不能仅靠前端按钮禁用。昵称在公开前做长度与内容约束，提供撤销入口；可后续按真实滥用情况增加验证，不预先上重型风控。

## 开发顺序与发布关卡

P0 可行性：原稿保真导入和 Codex 最小闭环并行推进；验收只读约束、实际来源覆盖、固定范围和最小回传。此处失败先解决，不拿手动复制聊天或随机抽签替代原需求。
P1 核心产品：匿名权限、领取、任务状态、完整结果、16 型目录、自选与原推荐分离；完成一型海报样板与最长内容分页。
P2 完整交付：16 张插画、封面/长图/全套多页与 ZIP、分享预览确认、撤销删除、后台与反馈。
P3 发布：全部 16 型保真和逐页视觉验收；桌面 Chrome、真实 iOS Safari / Android Chrome 保存验证；越权、竞态、到期、重复提交、服务重启与备份恢复；沿用 CI → staging → 精确版本生产发布。

文档标注的 MVP 包含较多完整能力，属于中等规模独立模块，不应按一个简单卡片页面估工。P0 完成后再根据兼容范围与导出实测结果排期；此轮不承诺未经验证的天数。

## 成本与当前缺口

站点每次匹配不新增服务端模型调用；分析仍消耗用户 Codex 自身额度，字符上限不是 Token 或费用承诺。16 张插画是固定内容生产，运行成本主要是静态图片/字体流量、任务存储和维护。先复用现有 ECS，不预先引入 Redis、第二个数据库或新服务器。图片流量增长后再评估 OSS/CDN；未查询云报价，不报虚构金额。

两份文档足够开始 P0。文档提到的原始紫色参考图和旧 HTML/PNG 多页模板本轮未提供，不能宣称已检查；可按文字设计重新制作，若要求视觉严格复刻参考，需要补充对应素材。Codex 目标版本、读取范围和移动保存能力仍待实测。现有账号/后台可复用，但匿名权限与领取逻辑必须新建。
