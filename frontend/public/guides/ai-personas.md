# AI 门道人格使用教程

核验日期：2026-09-18。入口：https://ruming.top/personas 。

人格是一组表达风格指令，不是新模型，也不会改变工具权限、准确率或安全规则。站内示例为人工编写，不是模型实时回答。

## 1. 本次对话

1. 选择人格及强度，在使用范围中选择“本次对话”。
2. 点击“复制指令”，粘贴到当前 AI 对话，再提出实际问题。
3. 发送“恢复默认语气”即可要求结束当前风格；不要要求工具把临时设定写入记忆或配置。
4. 新对话通常需要重新粘贴；长对话中的遵循程度也会受上下文影响。

## 2. Codex Skill

以元气搭子为例：

1. 选择“Codex Skill”，下载 SKILL.md。
2. 建立用户技能目录 `~/.agents/skills/mendao-spark/`，把 SKILL.md 放进去。项目专用可放在项目 `.agents/skills/mendao-spark/`。
3. 下载文件可能被浏览器重命名为 SKILL (1).md，安装时应恢复为 SKILL.md。
4. 检查技能列表；未出现时重启 Codex。可在支持的选择器中选择技能，或使用网页提供的明确调用口令。
5. 示例口令：`请使用 $mendao-spark，仅在本次对话采用这个人格，不修改长期配置。`
6. 安装不等于默认生效。为禁止隐式匹配，可在该技能目录下增加 `agents/openai.yaml`：

```yaml
policy:
  allow_implicit_invocation: false
```

卸载只删除该人格目录，不删除其他技能。

## 3. 项目或全局默认

1. 选择“项目默认”或“全局默认”，复制生成配置。
2. 先备份实际配置文件。
3. 项目默认：合并到项目根目录 `AGENTS.md`。全局默认：合并到 `~/.codex/AGENTS.md`；设置过 CODEX_HOME 时以实际目录为准。
4. 不覆盖原有文件内容。只新增或替换 `<!-- mendao-persona:start -->` 和 `<!-- mendao-persona:end -->` 之间的人格配置，保留标记；同一文件只保留一段人格设置。
5. 存在 `AGENTS.override.md` 时应检查实际加载文件，不能假设 AGENTS.md 一定被读取。项目或更近目录的指令也可能覆盖全局风格。
6. 新开会话或重启，观察实际回复。

验证问题：“请说明当前交流风格，再用两句话帮我规划今天的工作。”结合实际回复判断，不仅凭模型声称已生效。

临时恢复：说“恢复默认语气”。长期恢复：删除两个标记之间的整段人格设置及标记，保留其他规则，再新开会话。直接删除整个 AGENTS.md 可能破坏其他项目规范，请勿这样操作。

## 4. 其他产品

普通聊天产品可直接粘贴本次对话指令。如果提供自定义指令、项目指令或智能体设定，可在那里保存人格正文。具体取决于产品和账号；没有持久入口时，不能承诺永久生效。Codex 文件路径与 Skill 口令不是其他产品通用的安装方式。

## 5. 分享、收藏和费用

分享链接保留人格 ID、强度及使用范围；不包含你的聊天正文。下载的 SVG 分享卡片可在浏览器打开，也可导入支持 SVG 的设计工具。收藏仅保存在当前浏览器，不跨设备同步。

站内生成和导出指令不调用模型 API。把指令发送给目标模型后，仍计入其上下文并按该产品规则计费。语气强度调整的是指令，人工示例台词不会随之实时重写。
